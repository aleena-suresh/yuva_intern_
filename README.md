## 👩‍💻 About This Repository

# 🧹 Week 1 — Data Preprocessing

### Adult Census Income Dataset

Worked with the Adult Census Income dataset and performed the initial data preparation required for further analysis.

**Work completed:**

- 📥 Dataset acquisition
- 🧹 Missing value handling
- 🔍 Duplicate detection
- 📈 Outlier detection
- 🔤 Categorical encoding
- 📊 Basic visualizations
- 💾 Cleaned dataset generation

**Libraries:** Pandas • NumPy • Matplotlib • Seaborn

# 🔵 Week 3 — Unsupervised Learning

### K-Means Clustering

Applied **K-Means clustering** to identify groups within the Adult dataset.

**Techniques used:**

- StandardScaler
- K-Means clustering
- Elbow Method
- Silhouette Score
- Cluster analysis
- PCA visualization

The clustering process helped identify different groups of records based on their numerical characteristics.

---

# 🩺 Week 4 — Supervised Learning

### Diabetes Prediction

Built a machine learning model to predict diabetes using the **Pima Indians Diabetes Dataset**.

**Model:** Logistic Regression

**Steps performed:**

`Data → Preprocessing → Scaling → Training → Prediction → Evaluation`

**Evaluation metrics:**

- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix
- Classification Report

---

# 🧠 Week 5 — Deep Learning

### MNIST Handwritten Digit Classification

Built a neural network using **TensorFlow and Keras** to classify handwritten digits from 0 to 9.

**Model included:**

- Flatten layer
- Dense layers
- ReLU activation
- Dropout
- Softmax output layer

**Evaluation included:**

- Test accuracy
- Classification report
- Confusion matrix
- Training accuracy
- Validation accuracy
- Training loss
- Validation loss

The trained model and prediction results were also saved for future use.
