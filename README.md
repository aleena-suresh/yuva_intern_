# Yuva Intern – Data Science with Python

This repository contains the projects and practical tasks completed during my Yuva Intern Data Science with Python internship.

The internship helped me understand and apply different stages of a data science workflow, including data collection, preprocessing, exploratory data analysis, machine learning, clustering, deep learning, model evaluation, and visualization.

## Internship Tasks

### Week 1 – Data Acquisition, Cleaning and Preprocessing
- Collected and worked with the Adult Census Income Dataset.
- Handled missing values and duplicate records.
- Detected outliers using statistical methods.
- Encoded categorical variables.
- Created basic visualizations.
- Tools: Python, Pandas, NumPy, Matplotlib, Seaborn.

### Week 2 – Exploratory Data Analysis and Visualization
- Performed exploratory analysis on the cleaned Adult dataset.
- Studied numerical and categorical features.
- Created histograms, scatter plots, boxplots and correlation heatmaps.
- Identified important patterns and relationships in the data.

### Week 3 – Unsupervised Learning and Clustering
- Applied K-Means clustering to the Adult dataset.
- Used the Elbow Method to select the number of clusters.
- Evaluated clustering using Silhouette Score.
- Used PCA for two-dimensional cluster visualization.
- Generated cluster summaries and visualizations.

### Week 4 – Supervised Learning Model
- Developed a diabetes prediction model using the Pima Indians Diabetes Dataset.
- Performed data preprocessing and feature scaling.
- Implemented Logistic Regression.
- Evaluated the model using accuracy, precision, recall and F1-score.
- Generated a confusion matrix and prediction results.

### Week 5 – Deep Learning Application
- Worked with the MNIST handwritten digit dataset.
- Built a neural network using TensorFlow and Keras.
- Normalized image pixel values.
- Trained the model for handwritten digit classification.
- Evaluated the model using accuracy, classification report and confusion matrix.
- Visualized training and validation accuracy and loss.
- Saved the trained model and prediction results.

### Week 6 – Integrative Capstone Project
- Combined the concepts learned throughout the internship into an end-to-end data science workflow.
- Performed data preprocessing and exploratory analysis.
- Applied unsupervised clustering techniques.
- Implemented supervised machine learning.
- Evaluated model performance using appropriate metrics.
- Created visualizations and generated final results.
- Prepared a detailed project report with findings, challenges and recommendations.
